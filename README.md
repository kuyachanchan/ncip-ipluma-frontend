# IPluma Digital Signing Platform

IPLUMA SIGNING PLATFORM (IPLUMA) A secure, PNPKI-enabled digital signing system designed to streamline and modernize NCIP’s document processing workflows by providing an integrated, agency-controlled platform for electronic signatures. This system facilitates the preparation, routing, signing, and verification of official documents while ensuring authenticity, integrity, and non-repudiation through the use of DICT-issued digital certificates. It supports document-intensive operations with built-in tracking of status and activities, minimizing reliance on third-party applications. iPluma is structured to accommodate key functionalities such as document management, workflow routing, digital signature application, and audit logging, all accessible through a unified interface for authorized users across NCIP offices.
